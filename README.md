# Proyecto_Lenguaje_de_Programacion

## BiblioSmart

El frontend Django de demostración se encuentra en [`mi_proyecto/`](./mi_proyecto/).
Para iniciar el sitio:

```bash
cd mi_proyecto
python manage.py runserver
```

Abre `http://127.0.0.1:8000/`. Las credenciales y los registros son ficticios;
las acciones de formularios se mantienen en el navegador y no se conectan a una
base de datos ni a servicios de autenticación.
